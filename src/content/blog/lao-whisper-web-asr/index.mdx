## ໂຄງການນີ້ຄືຫຍັງ?

**Lao Whisper Web** ເປັນເວັບແອັບທີ່ຊ່ວຍຖອດຄວາມສຽງພາສາລາວໃຫ້ເປັນຂໍ້ຄວາມ (Automatic Speech Recognition — ASR) ໂດຍອັດຕະໂນມັດ. ຜູ້ໃຊ້ງານສາມາດ:

- **ອັບໂຫຼດໄຟລ໌ສຽງ** (MP3, WAV, MP4, FLAC ແລະ ຮູບແບບອື່ນໆ) ເພື່ອຖອດຄວາມ
- **ຖອດຄວາມແບບ Real-time** ຜ່ານໄມຄ໌ໂຟນໂດຍກົງ
- **ແກ້ໄຂຜົນລັບ** ແລະ ສົ່ງອອກເປັນ TXT, SRT, ຫຼື JSON
- **ເກັບຂໍ້ມູນ** ເພື່ອໃຊ້ Fine-tune ໂມເດລໃຫ້ຮັບຮູ້ພາສາລາວໄດ້ດີຂຶ້ນ

### Engine Abstraction Pattern

ແນວຄິດຫຼັກຄື ໃຊ້ **Abstract Base Class** ເພື່ອໃຫ້ສ່ຽນ AI Engine ໄດ້ງ່າຍ ໂດຍບໍ່ຕ້ອງປ່ຽນ code ຫຼາຍ:

```python
# base_engine.py
from abc import ABC, abstractmethod

class BaseASREngine(ABC):
    @abstractmethod
    def load_model(self, model_name: str): ...

    @abstractmethod
    def transcribe_file(self, audio_path: str, language: str) -> dict: ...

    @abstractmethod
    def transcribe_chunk(self, audio_bytes: bytes) -> dict: ...

    @abstractmethod
    def get_model_info(self) -> dict: ...
```

ຈາກນັ້ນ implement Engine ສຳລັບ Whisper Local:

```python
# whisper_local_engine.py
import whisper
from .base_engine import BaseASREngine

class WhisperLocalEngine(BaseASREngine):
    def __init__(self):
        self.model = None

    def load_model(self, model_name: str = "medium"):
        self.model = whisper.load_model(model_name)

    def transcribe_file(self, audio_path: str, language: str = "lo") -> dict:
        result = self.model.transcribe(
            audio_path,
            language=language,
            task="transcribe",
            word_timestamps=True
        )
        return result
```

<Callout type="info">
ການໃຊ້ `language="lo"` ຢ່າງຈະແຈ້ງສຳຄັນຫຼາຍ — ຖ້າບໍ່ force Whisper ຈະ output ພາສາໄທ ເພາະ pre-train ດ້ວຍຂໍ້ມູນໄທຫຼາຍກວ່າລາວ.
</Callout>

### Real-time Transcription ດ້ວຍ WebSocket

```python
# websocket_transcribe.py
from fastapi import WebSocket

@router.websocket("/ws/transcribe")
async def websocket_transcribe(websocket: WebSocket):
    await websocket.accept()

    try:
        while True:
            # ຮັບ audio chunk (2 ວິນາທີ) ຈາກ browser
            data = await websocket.receive_bytes()

            # ຂ້າມຖ້າງຽບ (VAD)
            if is_silence(data):
                continue

            engine = model_manager.get_engine()
            result = engine.transcribe_chunk(data)

            # ສົ່ງຜົນລັບກັບທັນທີ
            await websocket.send_json({
                "text": result["text"],
                "is_final": True,
                "confidence": result.get("avg_logprob", 0)
            })
    except Exception:
        await websocket.close()
```

### Upload Tab

```tsx
// UploadTab.tsx
"use client";
import { useState } from "react";

export function UploadTab() {
  const [file, setFile] = useState<File | null>(null);
  const [result, setResult] = useState<TranscriptResult | null>(null);
  const [loading, setLoading] = useState(false);

  const handleTranscribe = async () => {
    if (!file) return;
    setLoading(true);

    const formData = new FormData();
    formData.append("file", file);
    formData.append("language", "lo");

    try {
      const res = await fetch("/api/transcribe", {
        method: "POST",
        body: formData,
      });
      const data = await res.json();
      setResult(data);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="space-y-4">
      <input
        type="file"
        accept="audio/*,video/*"
        onChange={(e) => setFile(e.target.files?.[0] ?? null)}
      />
      <button onClick={handleTranscribe} disabled={loading}>
        {loading ? "ກຳລັງຖອດຄວາມ..." : "ຖອດຄວາມ"}
      </button>
      {result && (
        <p className="font-lao text-lg leading-8">{result.text}</p>
      )}
    </div>
  );
}
```

### Real-time Tab (WebSocket)

```tsx
// RealtimeTab.tsx
"use client";
import { useRef, useState } from "react";

const CHUNK_DURATION_MS = 2000; // ຕັດ audio ທຸກ 2 ວິນາທີ

export function RealtimeTab() {
  const wsRef = useRef<WebSocket | null>(null);
  const mediaRecorderRef = useRef<MediaRecorder | null>(null);
  const [transcript, setTranscript] = useState("");

  const startRecording = async () => {
    const stream = await navigator.mediaDevices.getUserMedia({ audio: true });

    const ws = new WebSocket("ws://localhost:8000/ws/transcribe");
    wsRef.current = ws;

    ws.onmessage = (event) => {
      const data = JSON.parse(event.data);
      setTranscript((prev) => prev + " " + data.text);
    };

    const recorder = new MediaRecorder(stream);
    mediaRecorderRef.current = recorder;

    recorder.ondataavailable = (e) => {
      if (e.data.size > 0 && ws.readyState === WebSocket.OPEN) {
        ws.send(e.data);
      }
    };

    recorder.start(CHUNK_DURATION_MS);
  };

  const stopRecording = () => {
    mediaRecorderRef.current?.stop();
    wsRef.current?.close();
  };

  return (
    <div className="space-y-4">
      <div className="flex gap-2">
        <button onClick={startRecording}>ເລີ່ມຟັງ</button>
        <button onClick={stopRecording}>ຢຸດ</button>
      </div>
      <div className="font-lao text-lg leading-8 min-h-32 p-4 border rounded">
        {transcript || "ລໍຖ້າການເວົ້າ..."}
      </div>
    </div>
  );
}
```

## ການ Normalize ຂໍ້ຄວາມລາວ

Whisper ອາດ output ຕົວໜັງສືໄທ ຫຼື artifacts ຕ່າງໆ — ຕ້ອງ normalize:

```python
# lao_text.py
import unicodedata
import re

def normalize_lao_text(text: str) -> str:
    # NFC normalization
    text = unicodedata.normalize("NFC", text)

    # ລຶບ Zero-width space ແລະ BOM
    text = text.replace("\u200b", "").replace("\ufeff", "")

    # ລຶບ Whisper artifacts
    artifacts = [
        r"\[BLANK_AUDIO\]",
        r"\[silence\]",
        r"\(inaudible\)",
        r"\[Music\]",
    ]
    for pattern in artifacts:
        text = re.sub(pattern, "", text, flags=re.IGNORECASE)

    text = re.sub(r"\s+", " ", text).strip()
    return text
```

### Script ກຽມຂໍ້ມູນ

```python
# prepare_dataset.py
import subprocess
import pandas as pd
from pathlib import Path

def prepare_audio(input_path: str, output_path: str):
    """ແປງ audio ໃຫ້ເປັນ 16kHz mono WAV"""
    subprocess.run([
        "ffmpeg", "-i", input_path,
        "-ar", "16000",
        "-ac", "1",
        "-y", output_path
    ], check=True)

def prepare_dataset(metadata_csv: str, audio_dir: str, output_dir: str):
    df = pd.read_csv(metadata_csv)
    output_path = Path(output_dir)

    for _, row in df.iterrows():
        audio_in = Path(audio_dir) / row["audio_path"]
        audio_out = output_path / "processed" / row["audio_path"]
        audio_out.parent.mkdir(parents=True, exist_ok=True)
        prepare_audio(str(audio_in), str(audio_out))

    train_df = df[df["split"] == "train"]
    valid_df = df[df["split"] == "valid"]
    train_df.to_csv(output_path / "metadata_train.csv", index=False)
    valid_df.to_csv(output_path / "metadata_valid.csv", index=False)
    print(f"ກຽມຂໍ້ມູນ: {len(train_df)} train, {len(valid_df)} valid")
```

### Script Fine-tune

```python
# run_finetune.py
from transformers import (
    WhisperForConditionalGeneration,
    WhisperProcessor,
    Seq2SeqTrainer,
    Seq2SeqTrainingArguments,
)
import torch

def run_finetune(
    base_model: str = "openai/whisper-medium",
    output_dir: str = "backend/models/lao-whisper-finetuned",
    num_epochs: int = 10,
):
    processor = WhisperProcessor.from_pretrained(base_model, language="lo")
    model = WhisperForConditionalGeneration.from_pretrained(base_model)

    # Force output ພາສາລາວ
    model.config.forced_decoder_ids = processor.get_decoder_prompt_ids(
        language="lo", task="transcribe"
    )

    training_args = Seq2SeqTrainingArguments(
        output_dir=output_dir,
        num_train_epochs=num_epochs,
        per_device_train_batch_size=8,
        learning_rate=1e-5,
        fp16=torch.cuda.is_available(),
        predict_with_generate=True,
        save_steps=500,
        eval_steps=500,
    )

    trainer = Seq2SeqTrainer(
        model=model,
        args=training_args,
        train_dataset=train_dataset,
        eval_dataset=valid_dataset,
    )

    trainer.train()
    trainer.save_model(output_dir)
    print(f"ບັນທຶກໂມເດລໃສ່: {output_dir}")
```

## ສິ່ງທີ່ຮຽນຮູ້ຈາກໂຄງການນີ້

### 1. Whisper + ພາສາລາວ
Whisper pre-train ດ້ວຍຂໍ້ມູນໄທຫຼາຍກວ່າລາວ → ອາດ output ໄທ ຖ້າບໍ່ force `language="lo"`

### 2. Chunk-based Real-time
Whisper ບໍ່ຮອງຮັບ true streaming — ໃຊ້ chunk 2 ວິນາທີ + VAD ຂ້າມ chunks ທີ່ງຽບ ເພື່ອປະຢັດ compute

### 3. Engine Abstraction
Abstract Base Class ຊ່ວຍ: test ກັບ `whisper_local` ກ່ອນ → deploy ດ້ວຍ `faster_whisper` ສຳລັບ production ໂດຍ code ສ່ວນໃຫຍ່ບໍ່ປ່ຽນ

### 4. Font ສຳລັບລາວ
ຕ້ອງ `line-height: 1.8` ຢ່າງໜ້ອຍ — ຖ້ານ້ອຍໄປ ວັນນະຍຸດຊ້ອນກັນ
