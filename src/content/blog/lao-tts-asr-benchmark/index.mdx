## TTS ແລະ ASR ຄືຫຍັງ?

ສອງ task ຫຼັກໃນ Speech AI:

- **ASR** (Automatic Speech Recognition) — ຟັງສຽງ → ແປງເປັນຂໍ້ຄວາມ (Speech-to-Text)
- **TTS** (Text-to-Speech) — ອ່ານຂໍ້ຄວາມ → ສ້າງສຽງ (Text-to-Speech)

ທັງສອງ task ສ້າງ **pipeline** ຮ່ວມກັນໄດ້:

```
ຂໍ້ຄວາມ → [TTS] → ສຽງ → [ASR] → ຂໍ້ຄວາມ
```

pipeline ນີ້ໃຊ້ ກວດ intelligibility ຂອງ TTS: ຖ້າ ASR ຖອດຄືນໄດ້ຖືກຕ້ອງ = TTS ສ້າງສຽງຊັດເຈນ.

<Callout type="info">
ໃນລາວ, ຍ້ອນຂໍ້ມູນລາວ pre-train ຂອງ Whisper ຍັງໜ້ອຍ — ຄ່າ ASR ທີ່ໄດ້ຈາກ Whisper ບໍ່ໄດ້ສະທ້ອນ intelligibility ຂອງ TTS ຢ່າງດຽວ ອາດຕ້ອງ Fine-tune Whisper ກ່ອນ benchmark.
</Callout>

## ເປັນຫຍັງຕ້ອງ Benchmark?

ການ benchmark ຊ່ວຍຕອບ:

- ໂມເດລໃດ **ຖ້ຽວກວ່າ / ຊັດກວ່າ** ສຳລັບພາສາລາວ?
- Fine-tuning **ຊ່ວຍຫຼາຍປານໃດ**?
- ໂມເດລ TTS ໃດ **ສຽງທຳມະຊາດ** ທີ່ສຸດ?

ໂດຍ benchmark ຕ້ອງກຳໜົດ:
- **Dataset** — ຊຸດຂໍ້ມູນທີ່ໃຊ້ທົດສອບ
- **Metrics** — ຕົວວັດຜົນ
- **Baseline** — ໂມເດລທີ່ໃຊ້ປຽບທຽບ

## Metrics ທີ່ໃຊ້

### ASR Metrics

**ຕົ້ນຕໍ: CER (Character Error Rate)**

ສຳລັບພາສາລາວ CER ດີກວ່າ WER ຍ້ອນພາສາລາວ **ບໍ່ມີຊ່ອງຄຳ** ຊັດເຈນ:

```
CER = (Substitutions + Deletions + Insertions) / Total Characters
```

ຕົວຢ່າງ:
```
Reference:  ສ  ະ  ບ  າ  ຍ  ດ  ີ
Hypothesis: ສ  ະ  ບ  ານ ດ  ີ
                       ^insert
CER = 1/7 ≈ 14.3%
```

**ຮອງ: SER (Syllable Error Rate)**

ໃຊ້ `laonlp.syllable_tokenize` ຕັດພະຍາງ ແລ້ວ compute WER ຂອງ syllable sequence:

```python
from laonlp import syllable_tokenize
from jiwer import wer

def compute_ser(refs, hyps):
    refs_syl = [" ".join(syllable_tokenize(r)) for r in refs]
    hyps_syl = [" ".join(syllable_tokenize(h)) for h in hyps]
    return wer(refs_syl, hyps_syl)
```

### TTS Metrics

| Metric | ຕົວຍ່ອ | ອະທິບາຍ | ດີ = |
|--------|--------|---------|------|
| Mean Opinion Score | **MOS** | ຄະແນນຈາກຄົນ 1–5 | ສູງ |
| Pseudo-MOS (ອັດຕະໂນມັດ) | **UTMOS** | ໂມເດລທຳນາຍ MOS | ສູງ |
| Mel Cepstral Distortion | **MCD** | ໄລຍະຫ່າງ spectral ຈາກ reference | ຕ່ຳ |
| Speaker Similarity | **SIM** | cosine similarity voice embedding | ສູງ |
| Intelligibility (via ASR) | **WER↓** | ຖອດຄວາມ TTS output | ຕ່ຳ |

<Callout type="warning">
MOS ຕ້ອງໃຊ້ **ຄົນຟັງ** ເທົ່ານັ້ນ — UTMOS ເປັນ proxy ທີ່ convenient ສຳລັບ dev loop ແຕ່ **ບໍ່ສາມາດແທນ** human evaluation ສຳລັບ production.
</Callout>

## ວິທີ Benchmark ດ້ວຍ Python

### Setup

```bash
pip install jiwer laonlp transformers datasets torch torchaudio
```

### Full Benchmark Script

```python
# lao_benchmark.py
import torch
from datasets import load_dataset
from transformers import pipeline
from jiwer import wer, cer
from laonlp import syllable_tokenize

# ─── ໂຫຼດ Dataset ───────────────────────────────────────
dataset = load_dataset("google/fleurs", "lo_la", split="test")

# ─── ໂຫຼດ ASR Model ──────────────────────────────────────
asr = pipeline(
    "automatic-speech-recognition",
    model="openai/whisper-large-v3",
    device=0 if torch.cuda.is_available() else -1,
    generate_kwargs={"language": "lo", "task": "transcribe"},
)

# ─── Normalize ──────────────────────────────────────────
def normalize(text: str) -> str:
    import unicodedata, re
    text = unicodedata.normalize("NFC", text)
    text = re.sub(r"\s+", " ", text).strip()
    return text

# ─── Run Benchmark ──────────────────────────────────────
references, hypotheses = [], []

for sample in dataset:
    ref = normalize(sample["transcription"])
    hyp = normalize(asr(sample["audio"])["text"])
    references.append(ref)
    hypotheses.append(hyp)

# ─── Compute Metrics ────────────────────────────────────
cer_score = cer(references, hypotheses)
wer_score = wer(references, hypotheses)

# SER — Syllable Error Rate
refs_syl = [" ".join(syllable_tokenize(r)) for r in references]
hyps_syl = [" ".join(syllable_tokenize(h)) for h in hypotheses]
ser_score = wer(refs_syl, hyps_syl)

print(f"CER : {cer_score:.4f} ({cer_score*100:.2f}%)")
print(f"WER : {wer_score:.4f} ({wer_score*100:.2f}%)")
print(f"SER : {ser_score:.4f} ({ser_score*100:.2f}%)")
```

### ຕົວຢ່າງ Output

```
CER : 0.0712  (7.12%)
WER : 0.1834  (18.34%)
SER : 0.1021  (10.21%)
```

<Callout type="info">
ຄ່າ WER ສູງກວ່າ CER ສະເໝີ ເພາະ 1 ຄຳທີ່ຜິດ = WER ຜິດ 1 ຄຳ ແຕ່ CER ຜິດພຽງ n ຕົວອັກສອນ. ສຳລັບລາວ **CER ເປັນ metric ຫຼັກ**.
</Callout>
