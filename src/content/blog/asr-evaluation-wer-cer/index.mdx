**Automatic Speech Recognition (ASR)** ຄືລະບົບ AI ທີ່ຟັງສຽງເວົ້າແລ້ວປ່ຽນເປັນຂໍ້ຄວາມໂດຍອັດຕະໂນມັດ — ຕົວຢ່າງທີ່ຫຼາຍຄົນຮູ້ຈັກ ເຊັ່ນ Siri, Google Voice, ຫຼື Whisper. ໃນການພັດທະນາ ASR ສຳລັບ **ພາສາລາວ**, ພວກເຮົາຕ້ອງຮູ້ວ່າໂມເດວດີຂຶ້ນຫຼືຮ້າຍລົງ — ນີ້ຄືຈຸດປະສົງຂອງ **Evaluation Metrics**.

## 01 — ຂໍ້ຜິດພາດ 3 ປະເພດຫຼັກ (S · I · D)

ໃນ ASR, ຂໍ້ຜິດພາດທີ່ໂມເດວເຮັດແບ່ງອອກເປັນ 3 ປະເພດ:

| ປະເພດ | ຊື່ | ຄຳອະທິບາຍ |
|---|---|---|
| **S** | Substitution | ຟັງໄດ້ຄຳໜຶ່ງ ແຕ່ຂຽນຜິດ — ເຊັ່ນ ໄດ້ຍິນ "ນ້ຳ" ແຕ່ຂຽນ "ນາ" |
| **I** | Insertion | ຂຽນຄຳທີ່ **ບໍ່ມີ** ໃນຕົ້ນສະບັບ — ຄືກັບ hallucination ລະດັບ ASR |
| **D** | Deletion | **ຂາດຄຳ** ທີ່ຄວນຢູ່ໃນ output — ຟັງບໍ່ຍິນ ຫຼື skip ໄປ |

<Callout type="info">
Metrics ທັງໝົດ (WER ແລະ CER) ໃຊ້ S, I, D ຄືກັນໝົດ — ສິ່ງທີ່ຕ່າງກັນຄືລະດັບທີ່ວັດ: **ລະດັບຄຳ (Word)** ຫຼື **ລະດັບຕົວອັກສອນ (Character)**.
</Callout>

## 02 — Word Error Rate (WER)

**WER** ແມ່ນ Metric ທີ່ໃຊ້ຫຼາຍທີ່ສຸດໃນໂລກ ASR. ມັນວັດຂໍ້ຜິດພາດ **ລະດັບຄຳ (Word-level)** — ຖ້າຄຳໃດຜິດ ຄຳນັ້ນຖືວ່າ "ຜິດທັງໝົດ" ຈະຜິດໂຕດຽວຫຼືສາມໂຕກໍ່ error ເທົ່າກັນ.

### ຕົວຢ່າງ Step-by-Step

```
Reference  : "the cat sat on the mat"
Prediction : "the cat sit on the"
```

| Token | the | cat | sat | on | the | mat |
|---|---|---|---|---|---|---|
| Reference | the | cat | sat | on | the | mat |
| Prediction | the | cat | **sit** | on | the | — |
| Label | ✅ | ✅ | S | ✅ | ✅ | D |

ໄດ້ S=1 (sit→sat), I=0, D=1 (mat ຂາດ), N=6

```
WER = (S + I + D) / N = (1 + 0 + 1) / 6 = 0.333 = 33.3%
```

**ສີ່ງທີ່ສຳຄັນແມ່ນ:**
- ↓ ຕ່ຳ = ດີ (0% = ສົມບູນແບບ)
- ບໍ່ມີ upper limit — ສາມາດ > 100% ໄດ້!

<Callout type="warning">
ຖ້າ prediction ຍາວກວ່າ reference ຫຼາຍ (Insertions ຫຼາຍ), WER ສາມາດເກີນ 100% ໄດ້ — ເຊັ່ນ predict 10 ຄຳ ແຕ່ reference ມີ 2 ຄຳ → WER = 500%! ຖ້າເຫັນແບບນີ້ໝາຍວ່າໂມເດວ "hallucinate".
</Callout>

## 03 — Character Error Rate (CER)

**CER** ວັດຄືກັນກັບ WER ແຕ່ **ລະດັບໂຕອັກສອນ**. ແບບນີ້ "ໃຈດີ" ກວ່າ WER ຍ້ອນວ່າ ຖ້າຄຳໜຶ່ງມີ 5 ໂຕ ແຕ່ຜິດ 1 ໂຕ ກໍ່ຖືວ່າໄລ່ເປັນ 4/5 ໂຕ.

ຈາກຕົວຢ່າງດຽວກັນ: "sit" vs "sat" — "s" ຖືກ, "**i**→**a**" ຜິດ (S=1), "t" ຖືກ, D=4 (mat ຂາດ + i (1)). ລວມ reference 22 characters:

```
CER = (1 + 0 + 4) / 22 = 0.227 = 22.7%
```

CER ຕ່ຳກວ່າ WER ສະເໝີ ຍ້ອນ "partial credit" ລະດັບໂຕ.

| ໃຊ້ WER ເມື່ອ | ໃຊ້ CER ເມື່ອ |
|---|---|
| ພາສາທີ່ແຍກ "ຄຳ" ດ້ວຍ space ຊັດເຈນ (ອັງກິດ) | ພາສາທີ່ບໍ່ມີ word boundary ຊັດ (ຈີນ, ຍີ່ປຸ່ນ, ລາວ) |
| ຕ້ອງການ context understanding | Lao OCR ທີ່ metric ຕ້ອງ fine-grained |

<Callout type="info">
ສຳລັບ **ພາສາລາວ**, CER ສຳຄັນຫຼາຍ ຍ້ອນ Lao script ມີ ligature ແລະ diacritics ທີ່ ASR ອາດຜິດສ່ວນດຽວໄດ້ງ່າຍ — ຄວນ report ທັງ WER ແລະ CER ຄູ່ກັນ.
</Callout>

## 04 — Inverse Real-Time Factor (RTFx)

WER ວັດ *ຄວາມຖືກຕ້ອງ* ແຕ່ **RTFx** ວັດ *ຄວາມໄວ* ຂອງລະບົບ — ສຳຄັນຫຼາຍໃນ production.

```
RTFx = Audio Duration / Processing Time
```

ຕົວຢ່າງ: ໃຊ້ **10 ວິ** process audio ຍາວ **100 ວິ** → RTFx = 10. **ຍິ່ງສູງ ຍິ່ງດີ!**

| RTFx | ຄວາມໝາຍ | ເໝາະກັບ |
|---|---|---|
| **> 1.0** | ໄວກວ່າ Real-Time ✅ | Live transcription, streaming |
| **= 1.0** | ໄວພໍດີ Real-Time | ໃຊ້ໄດ້ use case ສ່ວນໃຫຍ່ |
| **< 1.0** | ຊ້າກວ່າ Real-Time | Batch processing offline |

<Callout type="info">
ໂມເດວດຽວກັນ ລັນໃນ GPU vs CPU ໃຫ້ RTFx ຕ່າງກັນຫຼາຍ — ຄວນ report RTFx ພ້ອມ hardware spec ສະເໝີ.
</Callout>

## 05 — Normalisation — ລຶບ Punctuation ກ່ອນ Evaluate

ໂມເດວເຊັ່ນ Whisper ຈະ predict ຂໍ້ຄວາມທີ່ **Orthographic** — ມີ uppercase, comma ຄົບ. ແຕ່ຖ້າ reference ບໍ່ຕ່ງກັນ WER ຈະ  **ຜິດ**.

```
Wav2Vec2 (ບໍ່ Normalize): HE TELLS US THAT AT THIS FESTIVE SEASON...
Whisper (Orthographic):   He tells us that at this festive season, with Christmas...
```

Whisper output ອ່ານງ່າຍກວ່າໃນ production ແຕ່ WER ສູງກວ່າ ຖ້າ reference ເປັນ uppercase.

**ທາງແກ້:** train orthographic, evaluate normalized — lowercase + ລຶບ punctuation ທັງ reference ແລະ prediction *ກ່ອນ* ຄິດ WER.

### ຄິດ WER

```python
from evaluate import load

wer_metric = load("wer")

reference  = "the cat sat on the mat"
prediction = "the cat sit on the"

wer = wer_metric.compute(
    references=[reference],
    predictions=[prediction]
)
print(f"WER = {wer:.4f} ({wer*100:.1f}%)")
# WER = 0.3333 (33.3%)
```

### ຄິດ CER

```python
from evaluate import load

cer_metric = load("cer")

cer = cer_metric.compute(
    references=[reference],
    predictions=[prediction]
)
print(f"CER = {cer:.4f} ({cer*100:.1f}%)")
# CER = 0.2273 (22.7%)
```

### Normalize ແລ້ວ Evaluate

```python
from transformers.models.whisper.english_normalizer import BasicTextNormalizer

normalizer = BasicTextNormalizer()

pred_text = " He tells us that at this festive season, with Christmas..."
ref_text  = "HE TELLS US THAT AT THIS FESTIVE SEASON WITH CHRISTMAS..."

norm_pred = normalizer(pred_text)
norm_ref  = normalizer(ref_text)

wer_norm = wer_metric.compute(
    references=[norm_ref],
    predictions=[norm_pred]
)
print(f"Normalized WER = {wer_norm*100:.2f}%")
# Normalized WER = 6.25%
```

<Callout type="tip">
WER ລຸດຈາກ ~33% ລົງ **6.25%** ຫຼັງ normalize — ຍ້ອນ case ແລະ punctuation ທີ່ "ບໍ່ຈຳເປັນ" ຖືກກຳຈັດ.
</Callout>

## 07 — Evaluate Whisper ກັບ Common Voice (ພາສາລາວ)

```python
from transformers import pipeline
from datasets import load_dataset
from evaluate import load
from tqdm import tqdm
from transformers.pipelines.pt_utils import KeyDataset
import torch

# 1. Load Whisper
pipe = pipeline(
    "automatic-speech-recognition",
    model="openai/whisper-small",
    torch_dtype=torch.float16 if torch.cuda.is_available() else torch.float32,
    device="cuda:0" if torch.cuda.is_available() else "cpu",
)

# 2. Load Common Voice Lao test set
cv_test = load_dataset(
    "mozilla-foundation/common_voice_13_0",
    "lo",  # "lo" = ລາວ, "dv" = Dhivehi
    split="test"
)

# 3. Batch inference
all_preds = []
for pred in tqdm(pipe(KeyDataset(cv_test, "audio"),
                      max_new_tokens=128,
                      generate_kwargs={"task": "transcribe"},
                      batch_size=32), total=len(cv_test)):
    all_preds.append(pred["text"])

# 4. ຄີດ WER
wer_metric = load("wer")
wer_ortho  = 100 * wer_metric.compute(
    references=cv_test["sentence"],
    predictions=all_preds
)
print(f"WER (Orthographic): {wer_ortho:.2f}%")
```

<Callout type="warning">
ຜົນ Dhivehi pre-trained (whisper-small): WER Orthographic = **167%** → ຫຼັງ normalize = **126%** — ໝາຍຄວາມວ່າ pre-trained model ຄຳ Dhivehi ເກືອບບໍ່ໄດ້ ຕ້ອງ **fine-tune** ກ່ອນ.
</Callout>

## ສຳລັບ Lao ASR — Evaluate ຢ່າງໃດ? (ສຳຄັນຫຼາຍ!)

ພາສາລາວ **ບໍ່ມີ word boundary ທີ່ຊັດເຈນ** ດ້ວຍ space — ດັ່ງນັ້ນການໃຊ້ WER ໂດຍກົງກັບ raw Lao text ແມ່ນ **ຜິດວິທີ**. ຕ້ອງເຂົ້າໃຈ 3 ທາງເລືອກ:

| Method | ດີ? | ບັນຫາ |
|---|---|---|
| **CER** | ✅ stable | ລະດັບ character — ດຸ/ຜ່ອນຄາຍເກີນ |
| **WER (word_tokenize)** | ⚠️ unstable | ຂຶ້ນກັບ tokenizer — ບໍ່ reliable |
| **SER (syllable_tokenize)** | ✅ ດີທີ່ສຸດ | stable, publishable metric |

### ບັນຫາຂອງ WER ກັບ Lao

ຖ້າໃຊ້ `jiwer.wer()` ໂດຍກົງກັບ raw Lao text — WER ຈະຜິດ ຍ້ອນ:

```
ຂ້ອຍກິນເຂົ້າ  →  ເປັນ 1 "word" ຫຼື 3 "words"?
```

ພາສາລາວຂຽນຕິດກັນ — `jiwer` ຈະ treat ທັງໝົດເປັນ 1 token. **WER ບໍ່ accurate**.

### Option A: ໃຊ້ CER (ງ່າຍ, stable)

```python
from evaluate import load

cer_metric = load("cer")

ref = "ຂ້ອຍກິນເຂົ້າ"
hyp = "ຂ້ອຍກິນເຂົາ"

cer = cer_metric.compute(references=[ref], predictions=[hyp])
print(f"CER = {cer*100:.1f}%")
```

### Option B: WER + Lao Word Tokenizer (laonlp)

ຖ້າຕ້ອງການ WER — ຕ້ອງ tokenize ກ່ອນດ້ວຍ `laonlp`:

```python
from jiwer import wer
from laonlp.tokenize import word_tokenize

def tokenize_lao(text):
    return " ".join(word_tokenize(text))

ref = "ຂ້ອຍກິນເຂົ້າ"
hyp = "ຂ້ອຍກິນເຂົາ"

ref_tok = tokenize_lao(ref)
hyp_tok = tokenize_lao(hyp)

print(f"WER = {wer(ref_tok, hyp_tok)*100:.1f}%")
```

<Callout type="warning">
`laonlp` word segmentation **ບໍ່ perfect** — WER ຈຶ່ງ **dependent on tokenizer quality**. ໃນ paper ຕ້ອງ mention ຊັດ: _"WER computed using laonlp tokenizer"_ ຖ້າບໍ່ດັ່ງນັ້ນ cross-paper comparison ຈະ invalid.
</Callout>

## Syllable Error Rate (SER) — Best Metric ສຳລັບ Lao ASR 🔥

ລະຫວ່າງ CER (ລະດັບ character) ແລະ WER (ລະດັບ word) — **SER (Syllable Error Rate)** ໃຊ້ **ພະຍາງ (syllable)** ເປັນ unit ທີ່ **stable ແລະ publishable ທີ່ສຸດ** ສຳລັບລາວ.

### ເປັນຫຍັງ Syllable-level ດີທີ່ສຸດ?

ພາສາລາວ:
- ❌ ບໍ່ມີ word boundary ຊັດເຈນ → WER unstable
- ❌ Character-level ລະອຽດເກີນ → CER ຕ່ຳ misleading
- ✅ ພະຍາງ (syllable) = ໜ່ວຍທາງພາສາສາດທີ່ stable ກວ່າ

```python
from jiwer import wer as compute_wer
from laonlp.tokenize import syllable_tokenize

def syllable_join(text):
    return " ".join(syllable_tokenize(text))

ref = "ຂ້ອຍກິນເຂົ້າ"
hyp = "ຂ້ອຍກິນເຂົາ"

ref_syl = syllable_join(ref)  # "ຂ້ອຍ ກິນ ເຂົ້າ"
hyp_syl = syllable_join(hyp)  # "ຂ້ອຍ ກິນ ເຂົາ"

ser = compute_wer(ref_syl, hyp_syl)
print(f"SER = {ser*100:.1f}%")
# SER = 33.3%  (1 ໃນ 3 syllables ຜິດ)
```

<Callout type="tip">
`syllable_tokenize` ຈາກ `laonlp` ຈະ split: `"ຂ້ອຍກິນເຂົ້າ"` → `['ຂ້ອຍ', 'ກິນ', 'ເຂົ້າ']` — ໜ່ວຍທີ່ stable ກວ່າ word segmentation ຫຼາຍ.
</Callout>

### Full Lao ASR Evaluation Pipeline

```python
from jiwer import wer as compute_wer
from evaluate import load
from laonlp.tokenize import word_tokenize, syllable_tokenize

def lao_asr_evaluate(references: list[str], predictions: list[str]):
    """
    ຄິດ CER + SER + WER ສຳລັບ Lao ASR
    ແນະນຳ: report CER + SER ໃນ paper
    """
    # ── 1. CER (main metric) ─────────────────────────
    cer_metric = load("cer")
    cer = cer_metric.compute(references=references, predictions=predictions)

    # ── 2. SER (syllable-level) ──────────────────────
    def syl(text):
        return " ".join(syllable_tokenize(text))

    ser = compute_wer(
        [syl(r) for r in references],
        [syl(h) for h in predictions]
    )

    # ── 3. WER (word-level, optional) ────────────────
    def tok(text):
        return " ".join(word_tokenize(text))

    wer = compute_wer(
        [tok(r) for r in references],
        [tok(h) for h in predictions]
    )

    print(f"📊 CER : {cer*100:.2f}%  ← main metric")
    print(f"📊 SER : {ser*100:.2f}%  ← syllable-level (recommended)")
    print(f"📊 WER : {wer*100:.2f}%  ← word-level (laonlp tokenizer)")

    return {"cer": cer, "ser": ser, "wer": wer}

# ── ທົດລອງ ────────────────────────────────────────────
refs = ["ຂ້ອຍກິນເຂົ້າ", "ລາວໄປຕະຫຼາດ"]
hyps = ["ຂ້ອຍກິນເຂົາ",  "ລາວໄປຕະຫຼາດ"]

results = lao_asr_evaluate(refs, hyps)
```
