## Kaggle ຄືຫຍັງ?

Kaggle ແມ່ນ Platform ອອນລາຍທີ່ຮວມທຸກຢ່າງທີ່ Data Scientist ແລະ AI Developer ຕ້ອງການໄວ້ຄົບໃນທີ່ດຽວ:

| Component | ໜ້າທີ່ |
|-----------|--------|
| **Datasets** | ຂໍ້ມູນຟຣີ 50,000+ ຊຸດ |
| **Notebooks** | Jupyter Cloud + GPU ຟຣີ |
| **Competitions** | ແຂ່ງ ML ຊິງລາງວັນຈາກບໍລິສັດຈິງ |
| **Courses** | ຄອດສ໌ຟຣີ Python, ML, SQL, DL |
| **Discussions** | Forum ຖາມ-ຕອບ ແລະ ແລກປ່ຽນ |

<Callout type="info">
Kaggle ໂດດເດັ່ນຈາກ Platform ອື່ນ ຍ້ອນ: Dataset + Notebook + Competition ຢູ່ Portal ດຽວ — ຂໍ້ມູນ Kaggle Dataset ສາມາດ Load ໂດຍກົງໃນ Notebook ໄດ້ທັນທີ ໂດຍໄມ່ຕ້ອງ Download.
</Callout>

## ຂັ້ນຕອນທີ 1 — ລົງທະບຽນ

## ຂັ້ນຕອນທີ 2 — ສ້າງ Notebook ທຳອິດ

Kaggle Notebook ຄ້າຍກັນກັບ Google Colab — Jupyter ໃນ Cloud, ຟຣີ, ບໍ່ຕ້ອງ Setup:

1. ຄລິກ **Code** ຢູ່ Menu ຊ້າຍ → **New Notebook**
2. ເລືອກ Python ເປັນພາສາ
3. ເລີ່ມຂຽນໂຕ Code:

```python
import pandas as pd
import numpy as np

# Load dataset ຈາກ Kaggle (ຫຼັງ Add dataset ແລ້ວ)
df = pd.read_csv('/kaggle/input/your-dataset/file.csv')
print(df.shape)
df.head()
```

4. ກົດ **Run** ຫຼື `Shift + Enter`
5. ກົດ **Save Version** ເມື່ອຕ້ອງການ Commit

**GPU ຟຣີໃນ Kaggle Notebook:**

| Resource | ຈຳກັດ/ອາທິດ |
|----------|------------|
| GPU (T4 x2) | 30 ຊົ່ວໂມງ |
| TPU v3-8 | 20 ຊົ່ວໂມງ |
| RAM | ~13 GB |
| Disk | ~73 GB |

ເປີດ GPU: **Settings Panel (ຂວາ) → Accelerator → GPU T4 x2**

<Callout type="tip">
GPU 30 ຊົ່ວໂມງ/ອາທິດ ຂອງ Kaggle ເໝາະກັບ Fine-tuning Model ຂະໜາດກາງ ຫຼື Train Model ໜ້ອຍໆ — ຖ້າຕ້ອງການ Train ຍາວ ໃຫ້ Mix ກັບ Google Colab.
</Callout>

## ຂັ້ນຕອນທີ 3 — ຊອກຫາ Dataset

ໄປທີ່ **Datasets** → ຄົ້ນຫາຂໍ້ມູນ:

```
ຕົວຢ່າງຄຳຄົ້ນຫາ:
- "titanic"         → ຂໍ້ມູນ Classic ML
- "lao language"    → ຂໍ້ມູນພາສາລາວ
- "speech audio"    → ຂໍ້ມູນສຽງ
- "stock price"     → ຂໍ້ມູນຫຸ້ນ
```

**ເພີ່ມ Dataset ໃນ Notebook:**

1. ເປີດ Notebook → **Add Data** (ໄອຄອນ `+` ດ້ານຂວາ)
2. ຄົ້ນຫາ Dataset ທີ່ຕ້ອງການ
3. ກົດ **Add** → Path ຈະເປັນ `/kaggle/input/dataset-name/`

```python
import os

# ກວດໄຟລ໌ທີ່ມີໃນ Dataset
for dirname, _, filenames in os.walk('/kaggle/input'):
    for filename in filenames:
        print(os.path.join(dirname, filename))
```

**Upload Dataset ຂອງຕົວເອງ:**

ໄປ **Datasets → New Dataset** → Upload ໄຟລ໌ `.csv`, `.zip`, ຫຼື Folder.

## ຂັ້ນຕອນທີ 4 — ເຂົ້າຮ່ວມ Competition

### Competition ທີ່ເໝາະສຳລັບ Beginners

| Competition | ປະເພດ | ລະດັບ |
|-------------|--------|-------|
| **Titanic** | Classification | ມືໃໝ່ທີ່ສຸດ |
| **House Prices** | Regression | ມືໃໝ່ |
| **Digit Recognizer** | Image Classification | ເລີ່ມ Deep Learning |

### ຂັ້ນຕອນ Submit

```
1. ໄປ Competitions → ເລືອກ Competition
2. ກົດ "Join Competition"
3. ສ້າງ Notebook → Train Model
4. ສ້າງໄຟລ໌ submission.csv
5. ກົດ "Submit Predictions"
```

**ຕົວຢ່າງ Titanic Submission:**

```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier

# Load data
train = pd.read_csv('/kaggle/input/titanic/train.csv')
test = pd.read_csv('/kaggle/input/titanic/test.csv')

# Simple feature engineering
features = ['Pclass', 'Sex', 'Age', 'SibSp', 'Parch', 'Fare']
train['Sex'] = train['Sex'].map({'male': 0, 'female': 1})
test['Sex'] = test['Sex'].map({'male': 0, 'female': 1})

X = train[features].fillna(0)
y = train['Survived']
X_test = test[features].fillna(0)

# Train
model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X, y)

# Submit
submission = pd.DataFrame({
    'PassengerId': test['PassengerId'],
    'Survived': model.predict(X_test)
})
submission.to_csv('submission.csv', index=False)
print("ສ້າງ submission.csv ສຳເລັດ!")
```

<Callout type="warning">
ໄຟລ໌ `submission.csv` ຕ້ອງມີ Column ຕາມທີ່ Competition ກຳໜົດ — ກວດ **Data** Tab ຂອງ Competition ເພື່ອເບິ່ງ Format ທີ່ຖືກຕ້ອງ.
</Callout>

## ລະບົບ Ranking ຂອງ Kaggle

Kaggle ມີ Tier System 4 ດ້ານ — ແຕ່ລະດ້ານ Progress ເປັນ Independent:

```
Novice → Contributor → Expert → Master → Grandmaster
```

| Tier | ສິ່ງທີ່ຕ້ອງເຮັດ (Competitions) |
|------|-------------------------------|
| Contributor | Profile ຄົບ + Notebook, Dataset, Discussion ຄົນລະ 1 ອັນ |
| Expert | Medal 2 ອັນ (Bronze ຂຶ້ນໄປ) |
| Master | Medal 1 Silver + 2 Bronze |
| Grandmaster | Medal 5 Gold |

<Callout type="tip">
**Tier ທີ່ Growth ງ່າຍສຸດ = Notebooks** — ຂຽນ Notebook ທີ່ Useful, ໄດ້ Upvotes ຫຼາຍ → ໄດ້ Medal ໄວ. ບໍ່ຕ້ອງ Win Competition ກໍ Rank ຂຶ້ນໄດ້.
</Callout>

## Tips ສຳລັບ Beginners

**1. ເລີ່ມຈາກ Titanic**

Titanic ເປັນ Competition Classic ທີ່ມີ Notebook ຕົວຢ່າງຫຼາຍທີ່ສຸດ — Fork Notebook ຂອງຄົນອື່ນ (ກົດ Copy and Edit) ມາຮຽນໄດ້ ບໍ່ຜິດ Rule.

**2. ອ່ານ Discussion ທຸກ Competition**

Discussion Tab ມີ Tips, Tricks, ແລະ EDA ທີ່ Community ແຊ໌ — ອ່ານກ່ອນ Train ຊ່ວຍປະຢັດເວລາຫຼາຍ.

**3. ໃຊ້ Kaggle API ດາວໂຫຼດ Dataset**

```bash
# ຕິດຕັ້ງ
pip install kaggle

# ຕັ້ງ API Key (ດາວໂຫຼດຈາກ Account Settings)
# ວາງໄຟລ໌ kaggle.json ໄວ້ທີ່ ~/.kaggle/

# ດາວໂຫຼດ Dataset
kaggle datasets download -d username/dataset-name

# ດາວໂຫຼດ Competition Data
kaggle competitions download -c titanic
```

**4. ລຳດັບ Learning Path ທີ່ແນະນຳ**

```
Kaggle Python Course

Kaggle ML Course
       ↓

House Prices (Regression Practice)
       ↓
ຂຽນ Notebook ດ້ວຍ EDA + ຂຽນ Discussion

Contributor Tier → Expert
```
