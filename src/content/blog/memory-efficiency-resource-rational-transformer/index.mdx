## ສະຫຼຸບໃນໜຶ່ງນາທີ

ຜູ້ຂຽນເຕີມ **Gaussian noise** ລົງໃນ value vectors ຂອງ Transformer ໂດຍ token ທີ່ຢູ່ໄກຈະໄດ້ຮັບ noise ຫຼາຍກວ່າ ຈາກນັ້ນບັງຄັບໃຫ້ model ຮຽນຮູ້ວ່າຈະໃຊ້ "ຄວາມແມ່ນຍຳຂອງໜ່ວຍຄວາມຈຳ" ຢ່າງປະຢັດພຽງໃດ

ຜົນສຳຄັນມີ 4 ຂໍ້:

- memory constraint ລະດັບປານກາງທຳນາຍ reading time ຂອງມະນຸດໄດ້ດີຂຶ້ນໃນບາງຊຸດຂໍ້ມູນ
- ບໍລິບົດຫຼາຍແບບຖືກບີບໃຫ້ມີ prediction representation ຄ້າຍກັນຫຼາຍຂຶ້ນ
- model ຖິ້ມລາຍລະອຽດສະເພາະບາງຢ່າງ ແຕ່ຮັກສາໝວດໝູ່ທີ່ເປັນປະໂຫຍດຕໍ່ການທຳນາຍ
- constraint ທີ່ແຮງຂຶ້ນບໍ່ໄດ້ດີຂຶ້ນສະເໝີໄປ

<Callout type="tip">
ແນວຄິດຫຼັກຂອງ paper ຄື working-memory capacity ອາດໝາຍເຖິງ **ຄຸນນະພາບ ແລະ ຄວາມລະອຽດຂອງ representation** ບໍ່ແມ່ນພຽງຈຳນວນ token ທີ່ເຂົ້າເຖິງໄດ້
</Callout>

## 1. Resource-rational ໝາຍເຖິງຫຍັງ?

ຄຳວ່າ *rational* ໃນທີ່ນີ້ບໍ່ໄດ້ແປວ່າ "ສົມບູນແບບ" ແຕ່ໝາຍເຖິງ **ການໃຊ້ຊັບພະຍາກອນທີ່ຈຳກັດໃຫ້ຄຸ້ມທີ່ສຸດສຳລັບງານທີ່ຕ້ອງເຮັດ**

ສົມມຸດວ່າມະນຸດມີ working-memory budget ຈຳກັດ ເຮົາບໍ່ສາມາດຈຳທຸກຄຳ ທຸກສຽງ ແລະ ທຸກລາຍລະອຽດໄດ້ຢ່າງແມ່ນຍຳເທົ່າກັນ ລະບົບຈຶ່ງຕ້ອງຫາຈຸດສົມດຸນລະຫວ່າງ:

$$
\text{ທຳນາຍຄຳຕໍ່ໄປໃຫ້ດີ}
\qquad\text{ແລະ}\qquad
\text{ໃຊ້ໜ່ວຍຄວາມຈຳໜ້ອຍ}
$$

ເຊັ່ນ ເມື່ອອ່ານປະໂຫຍກ:

> The doctor near the old building usually ...

ເຮົາອາດຈຳໄດ້ວ່າ subject ເປັນບຸກຄົນ ເປັນ animate entity ປະໂຫຍກຍັງລໍຖ້າ verb ແລະ ມີ modifier ແຊກຢູ່ ໂດຍບໍ່ຈຳເປັນຕ້ອງຮັກສາທຸກລາຍລະອຽດຂອງຄຳວ່າ *doctor* ໃຫ້ແມ່ນຍຳເທົ່າກັນ

## 2. ຈາກ "ຈຳ ຫຼື ລືມ" ສູ່ຄວາມຈຳທີ່ຄ່ອຍໆເລືອນ

ງານກ່ອນໜ້າມັກຈຳລອງຂໍ້ຈຳກັດຂອງ working memory ດ້ວຍ limited context, local attention ຫຼື ລຶບ token ເກົ່າ ວິທີເຫຼົ່ານີ້ມີຂອບແຂງ:

| ວິທີ | ພາບຂອງຄວາມຈຳ |
|---|---|
| Context window | ຢູ່ໃນ window ຈຶ່ງຈຳໄດ້; ຢູ່ນອກ window ຈຶ່ງຫາຍໄປ |
| Binary erasure | ເກັບ token ໄວ້ ຫຼື ລຶບຖິ້ມ |
| Paper ນີ້ | token ຍັງຢູ່ ແຕ່ representation ມີຄວາມລະອຽດຫຼຸດລົງຕໍ່ເນື່ອງ |

ງານນີ້ຕໍ່ຍອດແນວຄິດ **lossy-context surprisal** ຊຶ່ງມອງວ່າມະນຸດຄາດເດົາຄຳຖັດໄປຈາກບໍລິບົດທີ່ຜ່ານຊ່ອງທາງຄວາມຈຳແບບສູນເສຍຂໍ້ມູນແລ້ວ:

$$
\text{ບໍລິບົດຈິງ}
\rightarrow
\text{memory representation ທີ່ເສຍຂໍ້ມູນ}
\rightarrow
\text{ການຄາດເດົາຄຳຖັດໄປ}
$$

ຈຸດຕ່າງສຳຄັນຄື paper ນີ້ບໍ່ທຳລາຍ token ໂດຍກົງ ແຕ່ເຮັດໃຫ້ hidden representation ມີ noise

## 3. Model ເຮັດວຽກແນວໃດ?

ໃນ attention ປົກກະຕິ output ຂອງ query ຕຳແໜ່ງ $q$ ຄື:

$$
z_q=\sum_k a_{qk}v_k
$$

ໂດຍ $a_{qk}$ ຄື attention weight ແລະ $v_k$ ຄື value representation ຂອງ token ຕຳແໜ່ງ $k$ ງານນີ້ປ່ຽນ $v_k$ ເປັນ noisy value:

$$
\tilde v_{qk}\sim\mathcal N(v_k,\tau_{qk}^{-1}I)
$$

ຄຳສຳຄັນຄື **precision**:

$$
\tau=\frac{1}{\sigma^2}
$$

- $\tau$ ສູງ → variance ຕ່ຳ → noise ໜ້ອຍ → ຈຳແມ່ນ
- $\tau$ ຕ່ຳ → variance ສູງ → noise ຫຼາຍ → ຈຳບໍ່ຊັດ

Precision ຫຼຸດລົງຕາມໄລຍະທາງແບບ exponential:

$$
\tau_{qk}=\tau_0e^{-\theta(q-k)}
$$

ໂດຍ $q-k$ ຄືໄລຍະຈາກຄຳປັດຈຸບັນໄປຫາຄຳໃນອະດີດ, $\tau_0$ ຄື precision ສູງສຸດ ແລະ $\theta$ ຄື decay rate ທີ່ model ຮຽນຮູ້ເອງ

| ຄ່າ $\theta$ | ຄວາມໝາຍ |
|---|---|
| ສູງ | ຄວາມແມ່ນຍຳຂອງຄວາມຈຳເສື່ອມໄວ |
| ໃກ້ 0 | precision ແທບບໍ່ຫຼຸດຕາມໄລຍະທາງ |

<Callout type="info">
Paper ບໍ່ໄດ້ເຕີມ noise ລົງໃນ attention weights: **attention weight** ຕອບວ່າຈະດຶງຂໍ້ມູນຈາກໃສ ສ່ວນ **value precision** ຕອບວ່າຂໍ້ມູນທີ່ດຶງມາຍັງຊັດພຽງໃດ ນີ້ຄືການແຍກ retrieval ອອກຈາກ encoding quality
</Callout>

## 4. Model ຮຽນຮູ້ທີ່ຈະປະຢັດ memory ແນວໃດ?

Training objective ມີສອງສ່ວນ:

$$
\mathcal L=\mathcal L_{\text{next-word}}+\lambda\mathcal L_{\text{memory}}
$$

ສ່ວນທຳອິດບັງຄັບໃຫ້ທຳນາຍຄຳຖັດໄປໄດ້ດີ:

$$
-\log p(w_t\mid w_{<t})
$$

ສ່ວນທີ່ສອງລົງໂທດການໃຊ້ encoding precision ສູງ ເພາະ precision ສູງປຽບເໝືອນການໃຊ້ຊັບພະຍາກອນ working memory ຫຼາຍ ຜູ້ຂຽນທົດລອງ:

$$
\lambda\in\{0,\;0.001,\;0.01,\;0.1,\;1\}
$$

- $\lambda=0$: ບໍ່ມີຄ່າປັບໃນການໃຊ້ memory
- $\lambda$ ນ້ອຍ: ມີຂໍ້ຈຳກັດເລັກນ້ອຍ
- $\lambda$ ໃຫຍ່: precision ມີລາຄາແພງ model ຕ້ອງຍອມຮັບ noise ຫຼາຍຂຶ້ນ

ເມື່ອບໍ່ມີຄ່າປັບ head ສ່ວນໃຫຍ່ຮຽນ $\theta\approx0$ ເພາະການເກັບຂໍ້ມູນໃຫ້ແມ່ນທັງໝົດຊ່ວຍ next-word prediction ເມື່ອ constraint ເພີ່ມຂຶ້ນ lower-layer heads ເລີ່ມມີ decay ໄວກ່ອນ ສ່ວນ higher layers ຮັກສາ precision ໄລຍະໄກໄດ້ດົນກວ່າ

ຄຳອະທິບາຍທີ່ເປັນໄປໄດ້ຄື lower layers ຈັດການຂໍ້ມູນ local ເຊັ່ນຮູບຄຳ morphology ແລະ syntax ໄລຍະໃກ້ ສ່ວນ higher layers ເກັບຄວາມໝາຍໂດຍລວມ ແລະ dependency ໄລຍະໄກ ຢ່າງໃດກໍຕາມ ນີ້ເປັນ **interpretation** ຈາກຄວາມຮູ້ເດີມ ບໍ່ແມ່ນຜົນ probe ໂດຍກົງຂອງທຸກ head

## 5. Model ທີ່ທຳນາຍຄຳແຍ່ລົງ ອາດຄ້າຍມະນຸດຫຼາຍຂຶ້ນ

ຜູ້ຂຽນໃຊ້ surprisal ຈາກແຕ່ລະ language model ທຳນາຍເວລາອ່ານຂອງມະນຸດ:

$$
S(w_t)=-\log p(w_t\mid w_{<t})
$$

ຄຳທີ່ມີ probability ຕ່ຳຈະມີ surprisal ສູງ ແລະ ມະນຸດມັກອ່ານຊ້າລົງ ການທົດລອງຄອບຄຸມ:

| ຊຸດຂໍ້ມູນ | ວິທີວັດ | ຜູ້ເຂົ້າຮ່ວມ |
|---|---|---:|
| Provo | Eye tracking; first-fixation ແລະ total reading time | 84 |
| SPR Natural Stories | Self-paced reading | 181 |
| A-Maze Natural Stories | ເລືອກລະຫວ່າງຄຳຈິງກັບຄຳຫຼອກ | 100 |

Model regression ພື້ນຖານໃຊ້ word length, frequency, position ແລະ ຕົວແປຄວບຄຸມອື່ນ ຈາກນັ້ນເພີ່ມ surprisal ເຂົ້າໄປ ແລ້ວປຽບທຽບ held-out log-likelihood

ຜົນຊັດທີ່ສຸດຢູ່ທີ່ **SPR Natural Stories**: constraint ລະດັບປານກາງຊ່ວຍ human alignment ຫຼາຍທີ່ສຸດ ສ່ວນ Provo first fixation ມີແນວໂນ້ມດີຂຶ້ນເລັກນ້ອຍ ແຕ່ Provo total time ແລະ A-Maze ບໍ່ມີ improvement ຊັດເຈນ

<Callout type="warning">
ຂໍ້ສະຫຼຸບທີ່ເໝາະສົມຄື memory constraint **ສາມາດ** ເພີ່ມ human alignment ໃນ reading measure ບາງຊະນິດ ບໍ່ແມ່ນ "ຍິ່ງຈຳໄດ້ໜ້ອຍຍິ່ງຄ້າຍມະນຸດ"
</Callout>

Natural Stories ໃຊ້ບໍລິບົດຍາວ ແລະ ມີໂຄງສ້າງພາສາທີ່ພົບບໍ່ເລື້ອຍ ຈຶ່ງອາດເພິ່ງ working memory ຫຼາຍກວ່າ Provo ສ່ວນ A-Maze ມີພາລະການຕັດສິນໃຈເພີ່ມເຕີມ ຈຶ່ງອາດບໍ່ໄດ້ສະທ້ອນ incremental reading process ພຽງຢ່າງດຽວ

ເມື່ອ constraint ສູງຂຶ້ນ perplexity ໂດຍທົ່ວໄປກໍສູງຂຶ້ນ model ທຳນາຍຂໍ້ຄວາມແຍ່ລົງ ແຕ່ບາງຄັ້ງທຳນາຍພຶດຕິກຳມະນຸດໄດ້ດີຂຶ້ນ:

$$
\text{LM ທີ່ທຳນາຍຄຳດີທີ່ສຸດ}
\neq
\text{ແບບຈຳລອງມະນຸດທີ່ດີທີ່ສຸດ}
$$

## 6. Noise ປ່ຽນ attention ແນວໃດ?

ເມື່ອ memory constraint ປານກາງ model ໃຫ້ attention ກັບ token ໃກ້ຫຼາຍຂຶ້ນ ນັ້ນຄື locality bias ສາມາດເກີດຂຶ້ນເອງໄດ້ໂດຍບໍ່ຕ້ອງ hard-code local mask

ແຕ່ຄວາມສຳພັນນີ້ບໍ່ເປັນ monotonic ເມື່ອ constraint ຮຸນແຮງຫຼາຍ locality bias ກັບອ່ອນລົງ ເພາະ model ອາດບໍ່ແນ່ໃຈວ່າຕຳແໜ່ງໃດມີຂໍ້ມູນທີ່ເຊື່ອຖືໄດ້ ຈຶ່ງກະຈາຍ attention ກວ້າງ ແລະ ສະໝ່ຳສະເໝີຂຶ້ນ

ດັ່ງນັ້ນ encoding ແລະ retrieval ມີຄວາມສຳພັນກັນ ແຕ່ບໍ່ແມ່ນສິ່ງດຽວກັນ ແລະ attention weights ພຽງຢ່າງດຽວອາດບໍ່ພໍອະທິບາຍ working memory

## 7. Representation ຖືກບີບໃຫ້ແໜ້ນຂຶ້ນ

ຜູ້ຂຽນສ້າງປະໂຫຍກ 1,000 ຕົວຢ່າງໃນຮູບ:

> Det Noun1 Prep Det Noun2 Adv ...

ເຄິ່ງໜຶ່ງມີ Noun1 ເປັນ animate ແລະ ອີກເຄິ່ງເປັນ inanimate ຫຼັງ model ອ່ານເຖິງ adverb ຜູ້ຂຽນເກັບ log probability ຂອງຄຳຖັດໄປທຸກຄຳໃນ vocabulary ເຮັດໃຫ້ແຕ່ລະບໍລິບົດກາຍເປັນ vector:

$$
x_i\in\mathbb R^V
$$

ຈາກນັ້ນໃຊ້ PCA ຫຼຸດເຫຼືອ 50 dimensions ແລະ ວັດ Euclidean distance ລະຫວ່າງບໍລິບົດ:

$$
d_{ij}=\sqrt{(x_i-x_j)^\top(x_i-x_j)}
$$

ເມື່ອ constraint ສູງຂຶ້ນ mean pairwise distance ຫຼຸດລົງ ບໍລິບົດຕ່າງໆ ຈຶ່ງມີ prediction distributions ຄ້າຍກັນຫຼາຍຂຶ້ນ ກ່າວອີກແບບຄື representational space ຖືກ **compress**

ສິ່ງສຳຄັນຄື representation ໃນການທົດລອງນີ້ບໍ່ແມ່ນ hidden state ພາຍໃນ Transformer ແຕ່ເປັນພື້ນທີ່ທີ່ສ້າງຈາກ output probability distributions

## 8. Compression ເຮັດໃຫ້ບາງ category ຊັດຂຶ້ນໄດ້ແນວໃດ?

ເຖິງແມ່ນ animate ແລະ inanimate ບໍ່ໄດ້ແຍກເປັນສອງ cluster ຊັດຂຶ້ນຕາມສົມມຸດຖານ ແຕ່ temporal prepositions ຢ່າງ *before* ແລະ *after* ກັບແຍກຈາກ spatial prepositions ຊັດຂຶ້ນເມື່ອ memory constraint ເພີ່ມຂຶ້ນ

ຜູ້ຂຽນວັດການແຍກ cluster ດ້ວຍ silhouette score:

$$
s(i)=\frac{b(i)-a(i)}{\max(a(i),b(i))}
$$

ຜົນນີ້ບໍ່ຂັດກັບການ compression ເພາະ model ບໍ່ຈຳເປັນຕ້ອງບີບທຸກ dimension ເທົ່າກັນ ມັນອາດຖິ້ມ lexical nuance ເຊັ່ນຄວາມຕ່າງລະຫວ່າງ *doctor* ກັບ *lawyer* ແຕ່ຮັກສາ feature ທີ່ຊ່ວຍ prediction ເຊັ່ນ relation ເປັນ temporal ຫຼື spatial ແລະ ໂຄງສ້າງຖັດໄປໜ້າຈະເປັນ clause ຫຼື noun phrase

```text
ລາຍລະອຽດສະເພາະຫຼຸດລົງ
        ↓
ເກັບ feature ທີ່ຊ່ວຍງານ
        ↓
category ບາງຊະນິດຊັດຂຶ້ນ
```

ຢ່າງໃດກໍຕາມ paper ສະແດງຜົນນີ້ຊັດສຳລັບ preposition category ພຽງກໍລະນີດຽວ ຈຶ່ງຍັງບໍ່ຄວນສະຫຼຸບວ່າ constraint ເຮັດໃຫ້ linguistic category ທຸກປະເພດຊັດຂຶ້ນ

## 9. ທຽບກັບ local attention

| | Local-attention paper | Memory-efficiency paper |
|---|---|---|
| ເປົ້າໝາຍ | ສຶກສາ computational expressivity | ສຶກສາ cognitive plausibility |
| ສິ່ງທີ່ຈຳກັດ | token ມອງຕຳແໜ່ງໃດໄດ້ | value ທີ່ມອງເຫັນຍັງແມ່ນພຽງໃດ |
| ກົນໄກ | local mask ແບບຕາຍຕົວ | decay rate ຮຽນຮູ້ແຍກຕາມ head/layer |
| Token ໄລຍະໄກ | ເຂົ້າເຖິງບໍ່ໄດ້ເມື່ອຢູ່ນອກ window | ຍັງເຂົ້າເຖິງໄດ້ ແຕ່ມີ noise ຫຼາຍຂຶ້ນ |
| ຄຳຖາມ | recognize ພາສາໃດໄດ້ | ຄ້າຍພຶດຕິກຳມະນຸດພຽງໃດ |

Memory noise ເຮັດໃຫ້ locality bias ເກີດຂຶ້ນເອງໃນລະດັບໜຶ່ງ ແຕ່ encoding constraint ທີ່ແຮງຂຶ້ນບໍ່ໄດ້ເຮັດໃຫ້ local retrieval ເພີ່ມຂຶ້ນຢ່າງຕໍ່ເນື່ອງ ເຮົາຈຶ່ງບໍ່ສາມາດແທນ working memory ດ້ວຍ local attention ພຽງຢ່າງດຽວ

## 10. ຈຸດແຂງ

- ແຍກ encoding quality ອອກຈາກ retrieval mechanism ຢ່າງຊັດເຈນ
- ປ່ຽນ memory ຈາກ binary "ຈຳ/ລືມ" ເປັນ continuous precision

- ເຊື່ອມ cognitive theory, information theory ແລະ Transformer ເຂົ້າດ້ວຍກັນ
- ທົດສອບທັງ reading time ແລະ ໂຄງສ້າງຂອງ output representations
- ສະແດງຜົນທີ່ບໍ່ trivial: model ທີ່ perplexity ແຍ່ລົງອາດຄ້າຍມະນຸດຫຼາຍຂຶ້ນ

## 11. ຂໍ້ຈຳກັດສຳຄັນ

### Model ແລະ ພາສາຍັງມີຂອບເຂດຈຳກັດ

ງານນີ້ໃຊ້ model ສະໄຕລ໌ GPT-2 small ແລະ ພາສາອັງກິດ ຜົນອາດບໍ່ເໝືອນເດີມໃນ LLM ຂະໜາດໃຫຍ່ multilingual models ຫຼື architecture ສະໄໝໃໝ່

### Transformer ບໍ່ໄດ້ incremental ເໝືອນມະນຸດຈິງ

ເຖິງແມ່ນໃຊ້ causal mask ແຕ່ລະຫວ່າງ training Transformer ຄຳນວນຫຼາຍຕຳແໜ່ງແບບຂະໜານ ຂະນະທີ່ມະນຸດຮັບຄຳທີລະຄຳ ແລະ update memory state ຕໍ່ເນື່ອງ ຜູ້ຂຽນຈຶ່ງສະເໜີວ່າ RNN ຫຼື state-space model ອາດສົມຈິງກວ່າໃນອະນາຄົດ

### ໄລຍະທາງເປັນເສັ້ນຊື່ເກີນໄປ

Decay ໃຊ້ token distance $q-k$ ແຕ່ມະນຸດອາດຈັດຄວາມຈຳຕາມ hierarchical structure ຄຳສອງຄຳອາດຢູ່ໄກກັນໃນປະໂຫຍກແຕ່ໃກ້ກັນທາງ syntax

### ຍັງແປ $\lambda$ ເປັນ human capacity ບໍ່ໄດ້

ເຮົາບໍ່ສາມາດບອກໄດ້ວ່າ $\lambda=0.01$ ເທົ່າກັບ working-memory capacity ຂອງມະນຸດຈັກໜ່ວຍ ເຮັດໄດ້ພຽງສັງເກດວ່າລະດັບປານກາງກົງກັບຂໍ້ມູນບາງຊຸດຫຼາຍທີ່ສຸດ

### ຜົນ reading-time ບໍ່ສະໝ່ຳສະເໝີທຸກ corpus

ຜົນດີຊັດໃນ SPR Natural Stories ແລະ ມີແນວໂນ້ມໃນ Provo first fixation ແຕ່ບໍ່ຊັດໃນ total time ຫຼື A-Maze ຈຶ່ງເປັນຫຼັກຖານສະໜັບສະໜູນບາງສ່ວນ ບໍ່ແມ່ນ universal theory

### Gaussian noise ຍັງເປັນ simplification

Model ສົມມຸດວ່າ noise ຂອງ token ຕ່າງໆ ເປັນອິດສະລະກັນ ແຕ່ຄວາມຈຳມະນຸດມີ similarity-based interference ເຊັ່ນ ຄຳນາມທີ່ຄ້າຍກັນອາດລົບກວນກັນເປັນພິເສດ

## ບົດສະຫຼຸບ

ແນວຄິດໃໝ່ທີ່ສຸດຂອງ paper ບໍ່ແມ່ນພຽງ "ເຕີມ noise ແລ້ວຄ້າຍມະນຸດຂຶ້ນ" ແຕ່ຄື:

> Working-memory capacity ຄວນນິຍາມເປັນຄຸນນະພາບ ແລະ ຄວາມລະອຽດຂອງ representation ບໍ່ແມ່ນພຽງຈຳນວນ token ທີ່ເຂົ້າເຖິງ ຫຼື ດຶງກັບມາໄດ້

ເມື່ອຊັບພະຍາກອນມີຈຳກັດ model ຮຽນຮູ້ທີ່ຈະປ່ອຍລາຍລະອຽດທີ່ໄກ ຫຼື ມີປະໂຫຍດໜ້ອຍໃຫ້ເລືອນລົງ ຮັກສາຂໍ້ມູນລະດັບສູງ ທຳນາຍດ້ວຍຄວາມໝັ້ນໃຈໜ້ອຍລົງ ບີບບໍລິບົດຫຼາຍແບບໃຫ້ມີ representation ໃກ້ກັນ ແລະ ເກັບໝວດໝູ່ບາງຊະນິດທີ່ມີປະໂຫຍດຕໍ່ງານ

ບາງທີມະນຸດອາດເຂົ້າໃຈພາສາໄດ້ດີ ບໍ່ແມ່ນເພາະເຮົາຈຳທຸກຢ່າງ ແຕ່ເພາະເຮົາ **ລືມລາຍລະອຽດຢ່າງມີກົນລະຍຸດ ແລະ ຮັກສາໂຄງສ້າງທີ່ມີປະໂຫຍດໄວ້**
